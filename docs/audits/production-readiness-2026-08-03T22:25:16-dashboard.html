The 13 critical blockers

Every one independently re-verified against source before recording. Amber = touches money directly.

CB-9 PayFast ITN silently drops confirmed payments

Transport failure is indistinguishable from a bad signature, and the controller always returns 200 — so PayFast never retries. Buyer charged, order stays pending, no entitlement, no receipt, no alert, no reconciliation job.

PayFastDriver.php:139-150 · PayFastWebhookController.php:22-40

CB-6 Buyers can be charged twice for one entitlement

No ownership or pending-order guard in checkout; the purchases unique constraint silently no-ops the second grant. Deterministic — not a race.

CheckoutController.php:30-90

CB-13 PayFast receipts lost forever on queue failure

markPaid() commits, then queue dispatch throws before the 200 is returned. The retry finds the order already paid and skips receipts permanently.

PayFastWebhookController.php:22-40

CB-11 No backups exist anywhere

Bare Docker volumes on one VPS. migrate --force runs against production with nothing to restore from. Combined with CB-8 there is no recovery path from a bad migration.

scripts/ · docker-compose.prod.yml

CB-1 Account pre-hijacking via unverified email + OAuth auto-link

Register with a victim's email; when they "Sign in with Google" they land in the attacker's account — which their own OAuth then marks verified. Attacker retains password access.

AuthService.php:37-73

CB-10 Service worker serves one user's private DMs to the next

...defaultCache adds an "apis" bucket keyed by URL alone; profile scoping lives in a header Workbox ignores. Not in the logout purge list.

sw.ts:103,123 · auth-store.ts:143,154

CB-12 Redis is an unguarded SPOF for session + cache + queue

Outage = total outage. Worse, the feature-flag kill switch reads Redis too, so it fails during the exact incident it exists to contain.

Setting.php:32 · Features.php:56-59

CB-3 / CB-4 Unrestricted file upload (product + course)

['required','file','max:51200'] and nothing else — no MIME check, no extension allow-list, no scan. Arbitrary bytes served to buyers.

StoreProductController.php:67-69 · StoreCourseController.php:97

CB-2 Sanctum tokens never expire, no revocation route

'expiration' => null, no token-management endpoints. A leaked token is valid forever.

config/sanctum.php:53 · Auth/TokenController.php:32

CB-5 Every deploy SIGKILLs in-flight jobs

No stopwaitsecs, no stop_grace_period — both default to 10s. Laravel traps SIGTERM correctly, but Docker kills the container first, mid-ffmpeg-transcode.

docker/supervisord.conf · docker-compose.prod.yml:38-54

CB-7 N+1 on the main feed

ProfileResource costs 2–3 uncached queries per profile; a 20-post page issues ~40–60 extra. preventLazyLoading absent, and dev/CI run SQLite where it goes unnoticed.

ProfileResource.php:20-21 · Profile.php:362-386

CB-8 Migration down() destroys encrypted secrets

Narrows text→json back over ciphertext. Rollback either throws or truncates webhook HMAC secrets to 255 bytes.

2026_07_30_110000_widen_encrypted_columns.php:29-39

What is genuinely strong

  • IDOR (9.0) — the X-Profile-Id header is properly ownership-verified (owner or ProfileMember pivot); ~35 controllers follow a consistent scope-then-verify idiom.
  • SQL Safety (9.5) — all 42 raw-SQL sites use bindings; the one interpolated identifier is allow-listed immediately before use; migrations are 100% Schema-builder.
  • Secret Scanning (9.25) — zero secrets in tracked files or git history, verified including deleted-file history across 147 commits.
  • Order::markPaid() is textbook-correct — transaction + lockForUpdate + re-check + idempotent grant, with a real concurrency test. Payments is the best-tested domain in the repo.
  • Technical debt is unusually low — 10 TODOs, zero FIXME/HACK/XXX, zero commented-out blocks, zero @ts-ignore/any in authored web code, across ~1,100 files.
  • All 63 foreign keys declare explicit cascade behaviour; money is integer cents throughout.
